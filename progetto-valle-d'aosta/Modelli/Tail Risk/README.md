# Tail Risk

Questa cartella e' riservata al blocco:

[Introduzione] -> [Modelli M1-M4] -> [Copule (Residui)] -> [Forecasting]

Qui andra' l'analisi del rischio di coda sui residui dei modelli mean effect.

Obiettivi previsti:

- studiare la dipendenza in coda dei residui tra comuni;
- valutare eventi estremi con copule sui residui depurati dall'effetto medio;
- capire dove il modello medio lascia vulnerabilita' sistematiche.
